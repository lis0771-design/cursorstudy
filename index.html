김민수

소프트웨어 개발자

사용자에게 가치 있는 서비스를 만들고, 경험의 디테일을 기술로 풀어내는 개발자입니다.

소개 경험 성격 포부

“기술은 사람을 위해 존재한다”

소개

안녕하세요. 소프트웨어 개발자로서 사용자에게 가치 있는 서비스를 제공하고 싶은 김민수입니다. 대학에서 컴퓨터공학을 전공하며 프로그래밍의 기초를 다졌고, 졸업 후 2년간 스타트업에서 웹 개발 업무를 담당했습니다.

빠르게 변화하는 IT 업계에서 새로운 기술을 학습하고 적용하는 것에 큰 흥미를 느끼며, 특히 사용자 경험을 개선하는 기술적 솔루션을 찾는 것을 좋아합니다. 아무리 기술적으로 뛰어난 코드라도 실제 사용자에게 도움이 되지 않는다면 의미가 없다고 생각합니다.

귀사는 혁신적인 기술력과 우수한 개발 문화로 업계에서 인정받고 있습니다. 이러한 환경에서 저의 기술적 역량을 더욱 발전시키고, 의미 있는 프로젝트에 기여하고 싶습니다.

경험

  1. 졸업 후 — 현재

    웹 개발자 · 스타트업

    스타트업에서 2년간 웹 개발을 담당하며 빠르게 변화하는 제품 환경에 맞춰 기능을 구현하고, 사용자 경험 개선을 위한 기술적 접근을 고민해 왔습니다.

    • Web
    • JavaScript
    • HTML/CSS

  2. 대학교 3학년

    팀장 · 지역 상권 활성화 앱 · 교내 해커톤 우수상

    5명의 팀원과 함께 48시간 동안 React Native로 모바일 앱을 완성했습니다. 백엔드 API 설계부터 프론트엔드 구현까지 전 과정에 참여하며 풀스택 경험을 쌓았고, 짧은 시간 안에 역할을 나눠 프로젝트를 이끌었습니다.

    • React Native
    • API 설계
    • 리더십

  3. 대학교 4년

    프로그래밍 멘토 · 컴퓨터공학과 학회

    후배들에게 프로그래밍을 가르치며 복잡한 개념을 쉽게 설명하는 능력을 길렀습니다. 이 경험은 현재 팀 내 코드 리뷰와 기술 공유에도 큰 도움이 되고 있습니다.

    • 멘토링
    • 코드 리뷰
    • 기술 공유

성격

  1. 장점

    꾸준한 학습 의지

    새로운 기술 트렌드에 관심이 많아 개인 시간을 활용해 온라인 강의를 수강하고 사이드 프로젝트를 진행합니다.

  2. 장점

    협업과 소통

    팀 프로젝트에서 다른 개발자, 디자이너, 기획자와 원활히 소통하며 공동의 목표를 달성하는 것을 중요하게 생각합니다.

  3. 장점

    문제 해결 지향

    복잡한 버그나 기술적 이슈에 직면했을 때 포기하지 않고 다양한 접근 방법을 시도하여 해결책을 찾습니다.

  4. 개선 중

    완벽주의 성향

    때로는 코드의 완성도에 지나치게 집착하여 일정에 영향을 줄 수 있습니다. 우선순위를 명확히 하고 적정 수준의 완성도를 목표로 하는 연습을 하고 있습니다.

포부

  1. 적응

    팀의 일원으로

    귀사의 개발 문화와 코딩 컨벤션에 빠르게 적응하여, 팀의 일원으로서 역할을 다하겠습니다.

  2. 단기

    도메인을 익히며

    맡은 업무를 성실히 수행하면서 비즈니스 도메인에 대한 이해도를 높이고, 기존 팀원들과의 협업으로 개발 실력을 향상시키겠습니다.

  3. 중장기

    기술 리더로

    주니어 개발자를 멘토링하고, 클라우드와 마이크로서비스 아키텍처 전문성을 쌓아 서비스의 확장성과 안정성 향상에 기여하겠습니다.

    • Cloud
    • Microservices
    • Mentoring

궁극적으로는 귀사와 함께 성장하여 IT 업계에서 인정받는 개발자가 되고, 사용자에게 진정한 가치를 제공하는 혁신적인 서비스 개발에 핵심적인 역할을 담당하고 싶습니다.

HTML, CSS, JavaScript로 구성했습니다. 레이아웃은 Brittany Chiang의 포트폴리오에서 영감을 받았습니다.
